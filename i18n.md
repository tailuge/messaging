# Internationalization (i18n) Plan for Billiards Lobby

This document outlines the effort to localize the billiards lobby for Korea, Japan, and Vietnam.

## 1. Technical Infrastructure

### Language Detection & Persistence
- Use `navigator.language` to determine the initial language.
- Store user preference in `localStorage`.
- Support `?lang=` query parameter for overrides.
- Add a language selector in the `SettingsModal`.

### Translation System
- Create `src/client/i18n.js` to manage translations.
- Implement a lightweight `t(key, params)` helper.
- Use a central dictionary for English (en), Korean (ko), Japanese (ja), and Vietnamese (vi).
- The `i18n.js` will export a `t` function and a `setLanguage` function that updates a reactive `language` property in `userStore`.

## 2. String Extraction & Components

The following files contain hardcoded strings that must be replaced with `t(key)`:

- **`src/client/lobby.js`**: "Solo Practice", "Play Online", "Thanks for playing at...", footer text.
- **`src/client/online-panel.js`**: "No other players online yet. Invite a friend!", "Spectate", "Challenge", "Select game type", "Challenge {name}", "Send message", "Cancel", "Play Online ({n})", "Challenge received!".
- **`src/client/solo-panel.js`**: Rule labels like "Nine Ball", "Snooker", "3-Cushion drill", "Trickshot", "Research", etc.
- **`src/client/settings-modal.js`**: "Settings", "Preferences", "Dark mode", "Enable notifications", "Flip X Axis", "Use proxy to connect", "Graphics", "Quality", Quality levels (pixelated, etc), "Links", "Support", "Usage", "Share", "Stats", "Copied!", "Recent visitors".
- **`src/client/info-panel.js`**: "We have moved", "Could not load scores", "Connecting to server…", "HiScore", "Rankings", "Name", "Rating", "W", "L", "Rule", "Match", "Ago", "City".
- **`src/client/message-modal.js`**: "Chat with {name}", "No messages yet", "Message…", "Close".
- **`src/client/challenge-banner.js`**: "Challenge from {name}", "Accept", "Decline", "Waiting for {name} to accept.", "{name} declined.", "Cancel".
- **`src/client/utils.js`**: Relative time strings ("{n}s ago", etc) and emoji titles.

## 3. Implementation Steps

1. **Extraction**: Identify and extract all hardcoded strings from the files listed above into `src/client/i18n.js`.
2. **Component Integration**:
   - Update `StoreElement` in `src/client/user-store.js` or create a `I18nElement` to re-render when the language changes.
   - Replace strings with `t(key, params)`.
3. **Language Selector**: Add a language dropdown in the `SettingsModal` (Preferences section).
4. **Translations**:
   - **Korean (ko)**: Focus on polite, standard gaming terminology (e.g., "도전" for Challenge).
   - **Japanese (ja)**: Use appropriate honorifics and common billiard terms (e.g., "対戦を申し込む" for Challenge).
   - **Vietnamese (vi)**: Ensure proper accentuation and clear game names (e.g., "Thách đấu" for Challenge).
5. **Testing**:
   - Verify layout stability with longer Vietnamese strings.
   - Verify right-to-left if ever needed (not required for these three).
   - Verify font rendering for CJK characters.
